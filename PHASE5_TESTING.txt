PHASE 5: TESTING CHECKLIST
Simple Step-by-Step Testing

⸻

TEST 1: Create Document
1. Go to docs page
2. Click "New Doc" button
3. ✅ Should redirect to document editor
4. ✅ Check database - document should appear

TEST 2: Edit & Save Document
1. In the editor, change the title (e.g., "My Test Document")
2. Type some content in the editor
3. Wait 5 seconds (auto-save)
4. ✅ Status should show "All changes saved"
5. Refresh the page (F5)
6. ✅ Title and content should still be there

TEST 3: View Documents List
1. Go back to docs page
2. ✅ Your document should appear in the list
3. ✅ Title should be correct
4. ✅ Preview should show content

TEST 4: Open Document
1. Click on your document card
2. ✅ Should open in editor
3. ✅ Title and content should match

TEST 5: Delete Document
1. Click three dots (⋮) on a document
2. Click "Delete"
3. Confirm deletion
4. ✅ Document should be removed from list
5. ✅ Check database - document should be deleted
